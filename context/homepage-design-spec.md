# AI-Native 读书雷达｜首页设计规格

## 1. 首页目标与范围边界

首页目标是在用户进入页面后的 10 秒内，让用户理解：

1. 这是一个面向 AI 学习者与转型从业者的读书雷达。
2. 雷达上的每个点代表一本书或文字类内容。
3. 八个方向代表不同 AI 学习与实践领域。
4. 三层同心圆代表不同阅读难度或进阶阶段。
5. 推荐指数和推荐理由用于帮助用户判断是否值得读。

当前首页只做探索入口，不展开完整产品系统。

本阶段不包含：

- 后台系统；
- 用户体系；
- 复杂评分机制；
- 历史版本对比；
- 完整社区功能；
- 二级页面详情设计。

首页可以保留以下入口，但不展开后续页面：

- 推荐一本书；
- 查看完整书单；
- 评分说明。

## 2. 首页信息架构

| 区域 | 作用 |
|---|---|
| 顶部导航区 | 展示产品名称、价值主张和主要入口 |
| 首屏说明区 | 用短文案解释产品定位与雷达阅读方式 |
| 雷达主视觉区 | 展示八大领域、三层难度和书籍点位 |
| 快速筛选区 | 支持按关键词、领域、难度、推荐指数筛选 |
| 图例说明区 | 解释点、方向、圈层和领域颜色 |
| Hover 浮层 | 展示书名、作者、推荐指数和短推荐理由 |
| 详情侧边面板 | 展示选中书籍的完整判断信息 |
| 辅助入口区 | 提供推荐书籍、完整书单、评分说明入口 |

## 3. 页面布局结构

- 页面顶部为产品名称、简短定位语和入口按钮。
- 首屏标题强调“AI 书籍的领域、阶段与长期价值”。
- 机制说明使用三个短卡片表达：点、方向、圈层。
- 雷达主视觉占据页面核心区域，右侧为图例和详情面板。
- 筛选区与雷达保持邻近，便于用户边筛选边观察结果。
- 辅助入口区位于雷达下方，不压过雷达主视觉。

桌面端是当前优先布局目标。

## 4. 核心组件职责

| 组件 | 职责边界 |
|---|---|
| `HomePage` | 页面级容器，负责数据加载、筛选状态、hover 状态、选中状态和页面状态 |
| `RadarCanvas` | 展示雷达图结构、领域标签、圈层标签和书籍点位 |
| `RadarFilters` | 管理关键词、领域、难度、推荐指数筛选和清空操作 |
| `RadarTooltip` | Hover 时展示轻量书籍摘要 |
| `BookDetailPanel` | Click 后展示书籍详情，不替代完整详情页 |
| `RadarLegend` | 解释点、方向、圈层和领域颜色 |
| 基础 UI 组件 | 提供按钮、标签、分数、空态、加载态等通用表达 |

## 5. 核心用户任务流

1. 用户进入首页。
2. 用户看到产品标题、价值主张和雷达图。
3. 用户通过“点、方向、圈层”说明理解雷达机制。
4. 用户浏览八大领域和三层阶段中的书籍分布。
5. 用户 Hover 某个书籍点，查看基础信息。
6. 用户 Click 某个书籍点，查看完整详情卡片。
7. 用户通过关键词、领域、难度或推荐指数筛选缩小范围。
8. 用户从首页进入“推荐一本书”“查看完整书单”或“评分说明”入口。

## 6. 关键交互规则

| 交互 | 规则 |
|---|---|
| Hover 书籍点 | 当前点位高亮，同时显示轻量 tooltip |
| Tooltip | 只展示短信息，不展示大段内容 |
| Click 书籍点 | 当前点进入选中态，右侧详情面板固定展示完整信息 |
| 点击雷达空白区域 | 取消当前选中书籍 |
| 领域筛选 | 支持多选，命中书籍保持清晰，非命中书籍降噪 |
| 难度筛选 | 支持入门认知、方法实践、深度进阶 |
| 推荐指数筛选 | 支持 4 分以上、4.5 分以上 |
| 关键词搜索 | 支持按书名、作者、领域、难度和标签匹配 |
| 清空筛选 | 恢复默认筛选条件 |

## 7. 页面状态清单

| 状态 | 页面表现 |
|---|---|
| 默认态 | 展示全部书籍点，右侧提示选择一本书查看推荐理由 |
| 加载态 | 雷达区域展示加载占位，提示正在加载专业推荐数据 |
| Hover 态 | 当前点高亮，出现 tooltip |
| 选中态 | 当前点固定高亮，右侧详情面板展示完整信息 |
| 筛选态 | 更新当前结果数量，非命中点降噪 |
| 空结果态 | 保留雷达框架，提示当前条件下暂无书籍，并提供清空筛选 |
| 错误态 | 保留页面结构，提示数据暂不可用，并提供重试 |

## 8. 数据字段需求

首页数据沿用当前 `BookItem` 结构：

| 字段 | 用途 |
|---|---|
| `id` | 唯一识别书籍点 |
| `title` | 展示书名 |
| `subtitle` | 展示书籍副标题或内容定位 |
| `author` | 展示作者 |
| `cover` | 展示封面占位色或封面资源 |
| `domain` | 映射八大领域 |
| `difficultyLevel` | 映射三层阅读阶段 |
| `sectorIndex` | 领域扇区语义索引 |
| `ringIndex` | 难度圈层语义索引 |
| `x`、`y` | 当前原型中的雷达点位坐标 |
| `recommendationScore` | 展示推荐指数 |
| `reasonShort` | Hover tooltip 中的短推荐理由 |
| `reasonFull` | 详情面板中的完整推荐理由 |
| `fitFor` | 说明适合人群 |
| `takeaways` | 说明阅读收获 |
| `contentType` | 区分书籍、长文、报告 |
| `tags` | 展示标签并支持搜索 |
| `votesCount` | 展示专业推荐人数 |
| `sourceNote` | 展示专业来源说明 |

## 9. 内容与视觉约束

- 推荐理由必须具体，不写空泛套话。
- 页面应体现“结构化推荐”，而不是“热门榜单”。
- 详情信息要帮助用户判断是否适合自己阅读。
- 分类色只表达领域，不表达推荐高低。
- 推荐指数可通过点大小、描边、分数文本等方式表达。
- 不使用电商书城感、社区论坛感、过度科幻感、卡通化或炫技式渐变发光效果。

## 10. 当前实现注意点

- 当前首页已在 React 版本中实现主要探索闭环。
- 当前入口按钮尚未连接二级页面。
- 当前雷达点位由 mock 数据 `x`、`y` 控制，不自动根据领域和难度计算。
- 当前首页以桌面端展示为主。
